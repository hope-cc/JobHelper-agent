# 个人信息管理 Spec

## 背景

JobHelper 侧边栏已有「个人信息管理」入口，目前渲染为占位页（`PlaceholderPage`）。规划中，用户填写的个人信息最终会以**字典**形式传入后端，agent 只读取字典的**键**（不读取值，保护隐私）来识别字段，再由程序按键访问值，自动填写各招聘平台的简历投递表单。

本期先把「前端收集 + 保存」这一环做完整：参照飞书招聘简历投递填写页的布局，提供分区表单收集，并把整份信息持久化到 `data/personal`。agent 自动填表逻辑留待后续版本。

## 目标

- 将「个人信息管理」占位页替换为完整表单页，布局参照飞书招聘简历投递填写页
- 分七个分区收集：基本信息、教育经历、实习经历、项目经历、奖项、语言能力、自我评价
- 经历类分区支持「添加 / 编辑 / 删除」条目
- 提供「保存」功能，将整份个人信息以字典形式持久化到 `data/personal`
- 保存的字典键名稳定、语义清晰，供后续 agent 只读键使用

## 功能需求

### F1 页面与导航

- F1.1：点击侧边栏「个人信息管理」进入本页，替换现有占位页
- F1.2：页面为纵向分区表单，分区顺序：基本信息 → 教育经历 → 实习经历 → 项目经历 → 奖项 → 语言能力 → 自我评价

### F2 基本信息分区

- F2.1：包含填空字段：姓名、手机、邮箱、性别、年龄、所在地点、家乡
- F2.2：性别用下拉（男 / 女 / 其他）
- F2.3：个人证件为「证件类型（下拉）+ 证件号码 + 有效期」三个字段；证件类型选项：身份证、护照、港澳通行证、台湾居民来往大陆通行证、其他

### F3 教育经历分区

- F3.1：提供「添加」按钮，点击在列表中追加一张空表单
- F3.2：每条表单字段：起止时间（开始时间、结束时间）、学校名称、学历（下拉：初中及以下/高中/大专/本科/硕士/博士）、学历类型（下拉：统招/全日制/专升本/自考/成人教育/网络教育/函授/其他）、专业
- F3.3：已添加条目支持编辑、删除

### F4 实习经历分区

- F4.1：提供「添加」按钮，追加空表单
- F4.2：每条表单字段：起止时间（开始时间、结束时间）、公司名称、职位名称、描述（多行）
- F4.3：已添加条目支持编辑、删除

### F5 项目经历分区

- F5.1：提供「添加」按钮，追加空表单
- F5.2：每条表单字段：起止时间（开始时间、结束时间）、项目名称、项目角色、项目链接、描述（多行）
- F5.3：已添加条目支持编辑、删除

### F6 奖项分区

- F6.1：提供「添加」按钮，追加空表单
- F6.2：每条表单字段：获奖时间、获奖名称、描述（多行）
- F6.3：已添加条目支持编辑、删除

### F7 语言能力分区

- F7.1：提供「添加」按钮，追加空表单
- F7.2：每条表单字段：语言（下拉：中文/英语/日语/韩语/法语/德语/西班牙语/其他）、精通程度（下拉：入门/一般/良好/精通/母语）
- F7.3：已添加条目支持编辑、删除

### F8 自我评价分区

- F8.1：提供一个多行文本框，占满分区宽度

### F9 保存与加载

- F9.1：页面提供「保存」按钮，点击后把整份信息以字典形式提交后端，持久化到 `data/personal`
- F9.2：保存成功显示明确提示（成功 / 失败）
- F9.3：进入页面时自动加载已保存的信息回填各分区
- F9.4：保存的字典顶层含各分区键：基本信息、教育经历、实习经历、项目经历、奖项、语言能力、自我评价；经历类分区值为数组，元素为单条记录
- F9.5：删除分区内某条记录后保存，数组中也移除该条

## 非功能需求

- N1：自由文本字段不强制格式校验（手机、邮箱等可填任意内容）；枚举类字段（性别、学历、学历类型、证件类型、语言、精通程度）用下拉呈现
- N2：字典键名稳定、语义清晰（英文 snake_case），不随 UI 改动变化，供后续 agent 只读键使用
- N3：持久化格式为 JSON（UTF-8），存储于 `data/personal/` 下单一文件
- N4：后端不做业务逻辑，仅负责持久化与读取
- N5：前端字段定义集中在一处（字段配置），新增字段只需改配置与类型定义

## 不做的事

- agent 自动填表逻辑（后续版本）
- 字段格式校验（手机号、邮箱格式等）
- 多份档案 / 历史版本
- 图片 / 附件上传
- 数据导出 / 分享
- 投递进度模块

## 验收标准

- AC1：点击侧边栏「个人信息管理」进入本页，不再是占位提示
- AC2：页面按七个分区纵向展示
- AC3：基本信息区可填写姓名、手机、邮箱、性别、年龄、所在地点、个人证件（类型 + 号码 + 有效期）、家乡
- AC4：教育 / 实习 / 项目 / 奖项 / 语言各分区可「添加」空表单，填写后可「编辑」「删除」
- AC5：自我评价区为多行文本框
- AC6：点「保存」后 `data/personal` 下出现 JSON 文件，内容为含所有分区键的字典
- AC7：保存成功 / 失败有明确提示
- AC8：重新进入页面，已保存内容自动回填
- AC9：添加多条记录后，JSON 中对应键为数组且顺序与页面一致；删除后数组同步移除
- AC10：枚举字段以下拉呈现，其余为文本输入

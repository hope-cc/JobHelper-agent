# LaTeX 生成与 PDF 导出 Spec

## 背景

简历管理模块（第一期）已实现：简历 CRUD、文本块编辑（个人信息 + 正文内容）、画布连线排序。当前"生成简历"按钮和"下载"按钮均为占位，仅弹出"功能开发中"提示。

本期要将文本块数据和连线顺序转换为 LaTeX 简历文档，编译为 PDF，支持预览和下载。

## 目标

- 将画布上的文本块（个人信息 + 正文）按连线顺序转换为标准 LaTeX 简历格式
- 个人信息渲染为：姓名居中加粗 + 联系方式居中 + 照片右侧
- 正文按模块类型分组、合并，相同类型不重复标题
- 加粗和圆点列表正确转译为 LaTeX 对应语法
- 后端调用 pdflatex 编译生成 PDF
- 前端增加"预览"按钮，查看 PDF；"生成简历"按钮触发编译
- "下载"按钮下载编译好的 PDF

## 功能需求

### F1: LaTeX 代码生成

- F1.1：后端新增 LaTeX 生成模块，将 blocks + connections 转换为完整 `.tex` 文件
- F1.2：从第一个个人信息块开始沿连线链遍历，确定块顺序
- F1.3：生成的 `.tex` 文件保存在 `data/CV/{resume_id}.tex`

### F2: 个人信息 LaTeX 渲染

- F2.1：姓名居中、加粗、大号字体
- F2.2：姓名下方居中显示 手机号 | 邮箱 | 现居地（普通字体）
- F2.3：照片靠右显示（用 minipage 实现左右布局）

### F3: 正文标题区

- F3.1：模块类型（项目经历/实习经历/教育经历/专业技能）作为 section 标题
- F3.2：标题与正文之间用横线（`\titlerule`）分隔
- F3.3：标题颜色为 #365F91

### F4: 正文内容 LaTeX 渲染

- F4.1：`TextSpan[]` 中的加粗段落在 LaTeX 中渲染为 `\textbf{...}`
- F4.2：`bulletPoints=true` 的块渲染为 `\begin{itemize} \item ... \end{itemize}`
- F4.3：换行符转换为 LaTeX 换行 `\\` 或空行
- F4.4：时间跨度用 `\cvitemheader{正文第一行}{时间跨度}` 渲染于第一行末尾

### F5: 同类型块合并

- F5.1：顺序遍历连线链时，连续相同模块类型的正文块不重复写标题
- F5.2：同类型后续块的正文追加在已有内容后面，用 `\vspace{5pt}` 隔开

### F6: LaTeX 编译

- F6.1：后端调用 `pdflatex` 编译 `.tex` 文件生成 `.pdf`
- F6.2：编译超时限制 30 秒
- F6.3：编译错误时返回错误信息给前端
- F6.4：PDF 保存在 `data/CV/{resume_id}.pdf`

### F7: 预览与下载

- F7.1：编辑器工具栏"生成简历"按钮左边新增"预览"按钮
- F7.2：点击"生成简历" → 调用后端生成+编译 → 成功后弹出提示
- F7.3：点击"预览" → 在新标签页打开 PDF 查看
- F7.4：点击"下载" → 下载 PDF 文件

## 非功能需求

- N1：LaTeX 编译超时 30 秒
- N2：生成的 `.tex` 和 `.pdf` 均存储在 `data/CV/` 目录
- N3：无外部 API 依赖，完全本地编译

## 不做的事

- LaTeX 模板自定义选择
- 多栏布局
- 简历评分/优化建议
- 其他 TeX 引擎（xelatex/lualatex）
- LaTeX 在线编译/云端渲染

## 验收标准

- AC1：点击"生成简历"后，`data/CV/{id}.tex` 和 `.pdf` 文件被创建
- AC2：个人信息块渲染为：姓名居中加粗 + 联系方式居中 + 照片右侧
- AC3：正文块按连线链顺序排列，同模块类型合并不重复标题
- AC4：加粗文字在 PDF 中以粗体显示，圆点列表以 bullet item 显示
- AC5：时间跨度显示在正文第一行末尾
- AC6：标题颜色为 #365F91，标题与正文之间有横线
- AC7：点击"预览"在新标签页打开 PDF
- AC8：点击"下载"触发 PDF 文件下载
- AC9：编译失败时页面显示错误信息

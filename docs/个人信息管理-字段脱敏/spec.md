# 个人信息字段脱敏 Spec

## 背景

个人信息管理页已能采集并持久化整份个人信息（`data/personal/profile.json`）。agent 的 `getPersonalInfo` 工具会读取该文件，用于投递简历时填写表单——但该工具目前是**未实现的坏桩**（`@tool` 装饰器要求首个参数为参数模型，当前无参定义在模块导入时即抛 `TypeError`）。手机、证件号、邮箱等字段属于敏感信息，不应原样暴露给 agent / LLM。

本期为基本信息区每个字段增加「脱敏」勾选框：勾选后该字段被标记为敏感，agent 调用 `getPersonalInfo` 工具时该字段值以 `"***"` 替换；`profile.json` 持久化存储的仍是原值。同时把 `getPersonalInfo` 工具实现完整。

## 目标

- 基本信息区每个字段旁提供「脱敏」勾选框
- 勾选状态持久化，刷新 / 重进页面保持
- agent 调用 `getPersonalInfo` 时，被勾选字段的值以 `"***"` 替换，其余保持原值
- `data/personal/profile.json` 中始终保存原值，不被替换
- 实现 `getPersonalInfo` 工具（无参调用、读取 profile.json、按脱敏配置替换）

## 功能需求

### F1 脱敏勾选框（UI）
- F1.1：基本信息区每个字段（姓名、手机、邮箱、性别、年龄、所在地点、证件类型、证件号码、有效期、家乡）标签旁显示一个「脱敏」勾选框
- F1.2：勾选框默认不勾选
- F1.3：勾选仅标记敏感，不影响该字段本身的编辑与取值

### F2 持久化与回填
- F2.1：保存个人信息时，脱敏勾选状态一并持久化
- F2.2：重新进入页面，已保存的勾选状态自动回填

### F3 getPersonalInfo 工具
- F3.1：工具无需任何参数即可调用
- F3.2：读取本地持久化的整份个人信息
- F3.3：返回前，将「被勾选且值非空」的基本信息字段值替换为 `"***"`
- F3.4：未勾选字段、经历类分区内容、自我评价均保持原值
- F3.5：被勾选但值为空的字段，仍返回空字符串（不产生假数据）
- F3.6：返回整份个人信息（与持久化结构一致的键结构），以文本形式给到 LLM

## 非功能需求

- N1：脱敏是「读取时的视图变换」，任何情况下都不改写 `data/personal/profile.json` 中的原始值
- N2：脱敏勾选状态与字段值互为独立状态——勾选不影响值，值变化不影响勾选；勾选状态本身需持久化
- N3：工具经现有工具注册机制注册，可被 LLM 发现并调用
- N4：未保存过个人信息时调用工具，返回友好提示而非报错

## 不做的事

- 经历类分区（教育/实习/项目/奖项/语言）不加脱敏框（已确认）
- 修改 profile.json 中已存储的值
- 对「自我评价」等整体文本字段提供脱敏标记
- 脱敏分级 / 自定义掩码（如不同敏感级别用不同占位符）
- 多档案

## 验收标准

- AC1：基本信息区每个字段标签旁出现「脱敏」勾选框
- AC2：勾选若干字段并保存，重新进入页面，勾选状态保持
- AC3：让 agent 调用 `getPersonalInfo`，返回内容中被勾选字段值为 `"***"`，未勾选字段为原值
- AC4：检查 `data/personal/profile.json`，存储值均为原值，未被替换
- AC5：被勾选但值为空的字段，返回内容中仍为空字符串
- AC6：工具注册成功、可被 LLM 无参调用（无 import / 注册错误）
- AC7：未保存过个人信息时调用工具，返回友好提示而非报错
